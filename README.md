# GODOT PARTY · 主界面交互原型

原生 **Godot 4.7.2 stable** UI 工程（验证版本：`4.7.2.stable.official.ed1daf0bf`）。灰阶线框风格，全部界面均使用原生 Control 节点；通用设置页按输入数据实例化可编辑组件场景，没有烘焙界面图片；官方 Godot 蓝色机器人头通过独立 SVG TextureRect 显示。

## 打开与运行

1. 使用 Godot 4.7.2，导入 `project.godot` 并等待字体导入
2. 按 F6 运行主场景，或 F5 运行项目
3. 在 `main.tscn` 的 2D 编辑器直接调整主菜单 / 房间；设置布局在 `settings/components/*.tscn` 中编辑，内容通过 `settings/main_settings_schema.json` 与 `main.gd` 绑定

初始窗口 1280×720，原生设计视口 **1920×1080**，统一缩放保持 16:9。无需插件、账号或网络。

## 统一配色与字体

在 Godot 文件系统面板选中 **`ui/theme/ui_config.tres`**，在 Inspector 一次修改全局 RGBA、背景和字体/字号。包含全屏展示区及装饰层、主菜单/列表/大厅/设置页、卡片/弹窗/遮罩、错误/交互态、层级线、开关和 tooltip；设置页与独立示例不再使用各自的字体或 Theme。

普通节点的 Theme Overrides 仍优先；背景/线条关闭 `Use Global Color` 后可直接改本地颜色，开关和样式也有对应局部开关。已有字号层级和可编辑场景布局保留。配置分组、编辑器预览与覆盖规则见 [`docs/THEME.zh-CN.md`](docs/THEME.zh-CN.md)。

## 通用设置页（本轮新增）

- 可复用场景：`settings/settings_page.tscn`，实现：`settings/settings_page.gd`
- 根据输入生成页签、静态选项、下拉选项框、左右选项开关（点击切换与滑动动画）、数值框、数值滑条（含精确输入）、分隔线、说明、动作按钮、条件折叠分组和双槽位按键绑定
- 通过稳定 ID 调用 `configure` / `add_tab` / `add_option` / `get_value` / `get_values` / `set_value` / `clear`，无需硬编码节点路径
- 修改值调用传入的 `Callable(value, id)`；动作按钮调用 `Callable(id)`。初始化、滑块与数值框同步、静默回填不会重复应用；可选统一 `setting_changed(id, value)` 信号
- 按键绑定由组件场景组成「功能名称 / 主按键 / 次要按键」三列，支持展开分组和功能行子操作、自然滚动、组合键、清空 / 取消和同范围冲突检查。Esc 取消录入，Delete / Backspace 清空，单独修饰键不提交；录入时消费快捷键，不触发背景返回或截图
- 绑定值为 `[KEY_W, KEY_UP]` 等整数双槽数组（`0` 为空）；业务 `Callable(value, id)` 应用到 InputMap，组件本身不修改 InputMap。主界面与独立示例只修改 `party_demo_*` 动作，不覆盖 `ui_*`；F10 示例底部显示实际动作触发
- 主菜单设置页已经实际使用这套 API；显示模式和应用窗口分辨率通过传入回调接入，语音与 UI 音效仍是原型状态
- 完整中文文档和可复制接入代码：[`docs/SETTINGS_API.zh-CN.md`](docs/SETTINGS_API.zh-CN.md)
- 独立示例：打开 `examples/settings_demo.tscn` 按 F6；从运行中的主界面按 **F10** 进入，再按 **F10** 返回。示例修改后会更新底部预览、颜色与回调次数，可直观看到真实 Callable 被执行
- 独立示例中 F12 保存 `screenshots/17_settings_api_demo.png`
- 命令行：`godot --path . -- --settings-demo`。示例返回按钮用于重建 / 重置示例；不联网、不采集音频、不写盘
- 设置组件沿用当前 1920×1080 设计与主题；移植到其他设计尺寸时请调整场景尺寸和边距。主题字体现为完整 Noto Sans CJK SC，支持输入中文房间名与玩家名

## 主界面结构

- 左侧功能区：创建房间、加入房间、协议、设置、退出，五个按钮同宽、纵向排列
- 展示区铺满整个 1920×1080 画布，作为背景；原生色块示意前、中、远景，后续可替换为游戏全景、录制片段或实时游戏画面，当前只是静态占位
- 左侧标题 + Godot 蓝色机器人头与五个按钮的整体视觉宽度约为 432 px，功能区叠在背景上
- 已删除原顶栏、边角编号、页脚与散落信息；右下角唯一信息块集中显示按键提示、实际 Godot 版本、MOCK 玩法协议与当前 UI 场景路径 / 页面 / 弹层标识
- 右下角状态在页面、弹层与协议切换时实时更新；协议明确标为 MOCK，并未加载真实玩法代码
- 主界面右上角显示玩家资料按钮（名称在左、头像占位在右），不显示派对预备区；仅创建 / 加入房间后在大厅显示派对预备区
- “协议”指玩法协议选择，不是用户协议或隐私条款；两个选项均为界面模拟，未安装、加载或执行真实玩法协议

## 可点击流程

- 创建房间 → 配置弹窗（12 个 MOCK 主游戏、1–24 字房间名、可选遮罩密码、公开 / 仅限好友 / 仅限邀请；取消 / Esc 不创建）→ 8 人房间（房主视角，示例 3 人占位）→ 开始游戏 → 显示未接入真实游戏的流程反馈
- 加入房间后显示玩家视角（示例 4 人占位）；准备 / 取消准备同步更新本人行状态与准备人数
- 房主可循环切换大游戏、地图、回合；玩家仅可查看，不能修改房主设置
- 导入预设 → 明确标注模拟的示例预览 → 应用示例预设；导出预设 → 查看当前设置预览。两者均不读写本地文件
- 高级设置 → 随机地图顺序、启用游戏道具、自动平衡队伍；仅在当前会话保留，玩家视角只读
- 左下角离开游戏 → 返回主菜单
- 加入房间 → 房间列表 → 加入任一未满房间 → 大厅；满员按钮禁用
- 房间列表右上角“IP 直连” → 输入 IPv4 / IPv6 地址和 1–65535 整数端口（默认 7777）→ 模拟加入玩家大厅。地址和端口分开填写，不接受域名、URL 或带端口的地址；明确显示 MOCK 和“未建立连接”，不会创建套接字、解析 DNS 或发送网络请求；取消 / Esc 留在列表，重开清空草稿
- 创建时房间名去除两端空白，不能为空；密码可留空，最多 32 字，拒绝纯空白。密码始终遮罩；提交 / 取消 / Esc 后清空原始密码，大厅仅保留“已设密码 / 无密码”状态，不保存或显示原始密码。公开性和密码不进行真实访问控制；新建弹窗重开恢复默认房间名 / 公开性 / 空密码，主游戏保留选择
- 右上角玩家资料 → 编辑 1–12 字名称（自动去除两端空白）→ 保存；取消 / Esc 丢弃修改。头像仅占位、不上传；保存后主界面和大厅本人行使用同一名称，过长的本人行显示省略号、悬停查看全名；仅保留当前会话
- 协议 → 选择派对示例 A / B → 当前选择同步到右下角状态区 → 完成 / Esc 关闭；会话内保留选择
- 设置 → 独立设置页（默认语音设置）→ 语音设置 / UI 设置 / 关于 / 按键绑定四个原生 TabContainer 选项卡 → 返回主菜单 / Esc 返回
- 语音设置：输入设备下拉框安全枚举系统设备；未枚举到具体设备时明确显示系统默认占位，不填充虚构硬件；输入音量滑块 + 可键盘输入的百分比数值框，仅原型状态，不启动语音采集
- UI 设置：UI 音效音量原型滑块 + 可键盘输入数值框；显示方式下拉菜单为全屏显示 / 窗口化 / 无边框窗口，真实调整当前窗口；关于：显示当前实际引擎版本与原型接入范围
- 设置页移除左上角标题、提示和页签内重复标题；选项卡上移至 y=72，高度增至 810。每项左侧名称、右侧调节；各页内容均为真正的 ScrollContainer，滚轮滚动内容，页签、返回按钮和调试信息固定不动
- 按键绑定：第四个页签由 `settings/demo_bindings.gd` 生成，移动 / 交互组可折叠，跳跃行可展开空中冲刺子绑定。更改真实应用到演示 InputMap 动作；默认配置静默初始化后由调用方显式应用，不计入回调次数
- 选择窗口化后，点击小箭头展开 / 收起缩进的二级选项；分辨率宽度 640–7680 px、高度 360–4320 px。先编辑，再按“应用分辨率”调整真实窗口；切换其他显示模式时隐藏窗口子项
- 所有设置数值均为原生 SpinBox，支持选中文字并精确输入、Enter / 移开焦点提交、四舍五入与合法范围限制。音量为 0–100%、步长 / 精度 1%；宽高步长 / 精度 1 px，例如 80.6 → 81、1280.6 → 1281。滑块和数值框双向同步
- 设置项使用 VBoxContainer / HBoxContainer 的统一行高和垂直居中布局；名称、下拉框、滑块和数值框中线一致，二级分辨率字段沿用相同规则；顶层行 / 组之间有 1 px 细分隔线，折叠内普通子项仅保留层级短支线
- 鼠标位于数值框或滑块上时，滚轮优先滚动设置内容，不修改数值；展开的下拉菜单仍使用自己的滚轮行为。仅内容实际溢出时显示滚动条，不用空白占位强制滚动
- 本轮保留原有房间设计，不继续扩展大厅设置；后续大厅设置由主游戏自行设计
- 退出 → 二次确认 → 取消或真正关闭应用
- Tab / Shift+Tab 移动键盘焦点，Enter 确认，Esc 返回 / 关闭弹层
- F1 显示 / 隐藏几何标尺
- F11 从主界面开始，自动截取主界面、列表、房主房间、高级设置、玩家未准备 / 已准备，以及创建弹窗、独立设置页三个选项卡、退出与协议弹窗，最后回到主界面；忽略截图过程中重复按键。新增截图为 `07_lobby_host.png`、`08_lobby_guest.png`、`09_lobby_guest_ready.png`、`10_lobby_advanced.png`，`03_lobby.png` 同样保留房主视角；`11_create_game.png`、`12_settings_voice.png`、`13_settings_ui.png`、`14_settings_about.png` 是本轮新增截图，`04_settings.png` 保留为语音页兼容名称；`15_create_dropdown.png` 显示展开的可滚动游戏菜单，`13_settings_ui.png` 显示展开的窗口分辨率子项顶部，`16_settings_ui_scrolled.png` 显示滚动到底部后的帮助说明和完整应用按钮
- F11 另外生成 `18_ip_direct.png`（本机示例 IP，不提交联网）与 `19_player_profile.png`（资料编辑）；`01_main_menu.png` / `02_rooms.png` / `11_create_game.png` 更新为本轮新增控件。自动截图使用空密码，不截图真实密码
- F12 保存当前真实视口到 `screenshots/`

所有房间、玩家和演示反馈均为本地模拟；没有网络多人联机、真实玩法协议、玩法关卡或音频素材。语音输入和 UI 音效滑块只保存原型数值，均不修改 Master 总线；语音设备选择不会设置音频输入设备或打开麦克风。没有真实输入增益处理或音效管线。设置和协议选择只保留当前会话，不写入磁盘。中文字体现为完整 Noto Sans CJK SC Regular，支持用户输入中文名称（资产路径保留原名以兼容场景引用）。许可证见 `assets/FONT-LICENSE.txt`。

### 折叠层级连接线

统一用于普通 group、功能行子操作及条件 UI：展开箭头中心沿同一 x 垂直向下接本层竖线（无斜接），每个可见子项（含说明）在行中心从竖线接一段短横线到内容左边缘。同一折叠内普通子项之间不画自动长分隔线，与按键绑定一致；顶层分隔、展开子组收尾边界与显式 divider 保留。收尾横线从紧邻展开区的最深末级竖线开始，删去向左穿过外层缩进的多余段；顶层折叠后恢复普通行分隔。末尾嵌套竖线仍共享祖先收尾高度。

`group_details.tscn` 的 `HierarchyLine`、`BranchTemplate` 与缩进/行间距可在编辑器调整；分支通过场景模板生成。`divider.tscn` 的根节点保留布局和 API，`Stroke` 绘制裁短后的横线，不挪动任何交互区域。空子组不显示竖线；条件隐藏、动态插入、滚动与缩放都会按实际 Control 几何重新连接。几何测试不替代真实截图验收。
